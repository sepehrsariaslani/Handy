# Phase 6 — Notes and searchable knowledge

Handy now has a dedicated Notes tab. Notes storage, search, editing, and meeting linking work on SQLite **without a GPU**. AI organization with Qwen is optional.

## Workflow

1. In Notes, enter your private server URL and bearer API token. The token is only held in frontend memory.
2. Create and edit notes up to 12,000 characters; search Persian and English titles and bodies with SQLite FTS5.
3. Changes have optimistic version checks. Concurrent edits return HTTP 409 instead of silently overwriting data.
4. Optional **Organize with Qwen** extracts sections, key points and review questions. Key points must refer to real line-source IDs; invented source references are discarded.
5. Completed Meeting Mode jobs can be explicitly imported as separate notes from the meeting interface or by entering the job ID. Decision/task evidence retains its original utterance ID. Editing an imported note invalidates its old generated analysis.
6. Deleting a note does not delete its original meeting recording or transcript.

## API (single-tenant, authenticated)

- GET `/v1/notes?q=phrase&offset=0&limit=25`: full-text search
- POST `/v1/notes`: JSON with title and content
- GET `/v1/notes/{id}`: content, sources, optional analysis, version
- PUT `/v1/notes/{id}`: title, content, expected version
- DELETE `/v1/notes/{id}`: remove note and search index
- POST `/v1/notes/{id}/analyze`: optional Qwen model
- POST `/v1/notes/from-meeting/{job_id}`: explicit import after meeting analysis is completed

All API routes use `Authorization: Bearer HANDY_API_KEY`. A source ID confirms that a cited line exists; it does **not** prove every claim generated by the LLM is accurate.

## GPU is not mandatory

CPU-only notes, indexing, search, SQLite, authentication and API work without installing any AI model.

For CPU-based Whisper Large V3 transcription, set:

```bash
HANDY_ASR_ENABLED=true
HANDY_ASR_DEVICE=cpu
HANDY_ASR_COMPUTE_TYPE=int8
```

CPU Large V3 will be slower. For an inexpensive notes-only server, disable both workers:

```bash
HANDY_ASR_ENABLED=false
HANDY_LLM_ENABLED=false
```

Qwen3.5-9B is a **separate** private OpenAI-compatible model server. Official vLLM recipes recommend a single 24 GB GPU for that Qwen model. A quantized CPU model may run using a compatible endpoint, but processing may be slow. pyannote Community-1 can also run on CPU.

**Caution:** A 24 GB GPU suitable for Qwen alone is not a guarantee that Qwen, Whisper Large V3 and pyannote all fit and run at the required concurrency on that same GPU. Benchmark before sizing combined deployments. A larger GPU or separate 8 GB + 24 GB GPUs may be more practical for simultaneous inference.

## Privacy and known limits

This is **single-tenant**: one API key grants access to every note and meeting. There is no per-user authorization, mobile background capture, automatic calendar/TODO integration, embeddings, vector search or conversational memory yet. Do not give the same key to unrelated customers or expose the API without TLS and access controls. Backups, encryption, deletion retention and quotas remain deployment responsibilities.

Tests: `cd server && python -m pytest -q`. Frontend: `bun run lint && bun run format:check && bun run build`.
